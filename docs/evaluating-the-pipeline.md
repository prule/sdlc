# Evaluating the Delivery Pipeline

This guide moved into the plugin that now runs the pipeline:
**[sdlc-pipeline/docs/evaluating-the-pipeline.md](https://github.com/prule/sdlc-pipeline/blob/main/docs/evaluating-the-pipeline.md)**.

It explains how to tell whether each agent, review gate and context doc (`domain/`, `standards/`)
earns its place, using session reports and A/B ablations. Reports for this project's runs are in
[`reports/sessions/`](../reports/sessions/); run retrospectives are in
[`retrospectives/`](../retrospectives/).
